## Stochastic Processes and Gambling Games

The previous chapters had definitions and generally stated many facts about random variables.
However, we haven't done anything useful with them so far.
It's time to get moving and actually use the tools that we've built up so far.
We'll start by discussing random processes.

Generally speaking, a random process is a sequence of random variables $X_1, X_2, \dotsc$ all defined on some probability triple $(\Omega, \mathcal{F}, \mathbf{P})$.
